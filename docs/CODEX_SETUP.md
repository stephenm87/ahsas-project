# Codex Setup

When an AI agent (Codex) initializes a session for the AHSAS project, it should review:
1. `README.md`
2. `docs/ARCHITECTURE.md`
3. `docs/PRODUCT_CONTEXT.md`
4. `docs/KNOWN_ISSUES.md`

Agents must use Vite build tools via `npm run build` and `npm run dev`.
Node 22.x is strictly enforced.
