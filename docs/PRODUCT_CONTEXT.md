# Product Context

**AHSAS (Asian History at SAS)** is an educational platform designed for students taking Asian History. It offers a suite of interactive tools to aid historical research, synthesis, and writing.

## Core Audience
Students and educators at SAS (restricted via `@saschina.org` Supabase auth).

## Key Capabilities
- **Analysis:** Source Analyzer, Compare tool, Pieces.
- **Synthesis:** CER Builder (Claim-Evidence-Reasoning), Research Studio.
- **AI Integration:** Socratic Seminar synthesis (via Gemini), AI-assisted research feedback.
- **Progress Tracking:** Saves progress securely in Supabase per student.
- **Anti-AI C.E.C. Note Layer:** Encourages independent student thought while utilizing AI tools ethically.
