# AHSAS (Asian History at SAS)

A web-based educational platform for Asian History at SAS, built with Vite and vanilla JavaScript. Features multi-page HTML architecture and various interactive history tools.

## Features
- **Source Analyzer:** Primary source analysis
- **CER Builder:** Claim-Evidence-Reasoning
- **Research Studio:** AI-assisted research
- **Socratic Seminar:** AI synthesis via Gemini
- **Source Comparison & Timeline Tool**
- **Historical Pieces Analysis**
- **Anti-AI C.E.C. Note Layer**
- **Per-step export toolbar**

## Tech Stack
- Vite 6 + vanilla JS (multi-page HTML)
- Node.js 22.x
- Netlify Functions (Serverless backend)
- Supabase (PostgreSQL, Auth, RLS)

## Setup
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
