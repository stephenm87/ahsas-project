# Contributing to AHSAS

1. Fork the repository (`stephenm87/ahsas-project`).
2. Create a feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes following Conventional Commits format (`git commit -m 'feat: Add amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

Please refer to `docs/AI_DEVELOPMENT_WORKFLOW.md` for AI-assisted workflows.
