# Security Policy

## Supported Versions
Only the latest baseline (`baseline-2026-08-03`) and main branch are currently supported.

## Reporting a Vulnerability
If you discover a security vulnerability, please do NOT open a public issue.
Instead, send a direct communication to the repository owner or file a security advisory through GitHub.

- Ensure no real API keys (Gemini, Supabase) are committed.
- Environment variables should use placeholders in `.env.example`.
